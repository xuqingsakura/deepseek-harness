# Agent Note：侧边栏底部按钮双向切换；移除工作台面板头部

Status: implemented

[English](2026-08-16-desktop-sidebar-toggle-and-workbench-header.md) | 中文

## 问题

侧边栏/工作台两个 UI 问题：

1. 活动栏底部的「收起侧边栏」按钮只能收起（带 `if (!collapsed)` 守卫），
   收起后再点无反应，而顶部品牌按钮可以双向切换。
2. 工作台文件树面板在侧边栏自己的面板标题下方又渲染了一行冗余头部
   （「工作台」+ 会话 cwd + ✕ 关闭按钮）。

## 决策

1. 移除 `if (!collapsed)` 守卫，让底部按钮成为完整双向切换（与品牌按钮
   的 label/aria 语义一致）。布局 store 的 `toggleSidebar` 改为感知视图：
   工作台视图下重新展开时恢复 `WORKBENCH_SIDEBAR_WIDTH`（300px），而非
   浏览器默认宽度。
2. 整体移除工作台面板头部（标题、cwd、✕）。侧边栏自己的面板标题已显示
   「工作台」；cwd 仍内部解析（文件树以它为根）。随之无用的 `layout`
   prop 从树面板删除。

## 影响

底部按钮在两种视图下都能收起/重新展开侧边栏；工作台面板只保留「文件」标签行
加文件树，与侧边栏标题一致。树的关闭走活动栏（折叠按钮/视图切换），不再有
面板内 ✕。

## 备选方案考量

- **只修底部按钮、store 保持不变** —— 按钮能再次切换，但工作台视图重新展开时会恢复浏览器默认宽度而非工作台的 300px，文件树会跳动。被否决：store 必须视图感知。
- **保留面板头部但重新样式** —— 侧边栏已在 slot 上方渲染自己的「工作台」面板头部，面板内这一行重复了它。被否决：冗余；✕ 也可通过活动栏触达。
