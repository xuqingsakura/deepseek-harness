# Agent Note：工作台编辑器标签

Status: implemented

[English](2026-08-16-workbench-editor-tabs.md) | 中文

## 问题

工作台文件查看器一次只显示一个文件，无法同时保留多个打开的文件，也无法快速切换。

## 决策

在工作台查看器上方增加 VS Code 风格的编辑器标签栏。在文件树中打开文件时，
将其追加到标签列表（按路径去重）并激活；点击标签激活对应文件；× 按钮关闭
标签，关闭当前激活标签时激活其右侧邻居（否则回退到左侧）。标签显示文件类型
徽标（按扩展名推导的缩写 + 强调色）、文件基名和悬停关闭按钮。

状态保存在共享的工作台状态句柄中：`openPaths`（打开顺序）加原有
`activePath`，并提供 `open(path)` / `close(path)` 修改器。文件树调用
`open`；查看器在 `FileViewer` 上方渲染 `WorkbenchTabs`。通过头部切换
按钮切换绑定会话时，会丢弃上一会话的标签。原先私有于 `FileViewer` 的
扩展名→语言映射移到 `file-lang.ts`，标签徽标元数据也归它所有。

## 备选方案

- 在标签栏内复制映射。否决：两份扩展名表会漂移；共享模块同时拥有高亮提示
  与徽标。
- 跨会话保留打开标签。否决：路径是会话相对的，切换 cwd 后会静默重读（或
  失败），因此切换会话时清空标签列表。

## 影响

工作台中间列可以同时保留多个打开文件；激活文件保持文件树高亮，切换标签时
查看器重新读取。标签状态是临时的（不持久化），与只读查看器的会话作用域
特性一致。
