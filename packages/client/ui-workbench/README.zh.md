# @deepseek-ai/dsh-client-ui-workbench

[English](README.md) | 中文

工作台 UI 插件（浏览器半）：会话头部开关将布局切换为文件工作台视图——左侧边栏为带标签页的面板（文件树 / 终端 / Git / 后台任务），中间列为 CodeMirror 编辑器，对话移动到右侧列——全部由会话级 workbench Remote（`ctx.remote.workbench`）支撑，后者在宿主上分别走 `ctx.fs`、子进程与系统 `git` 可执行文件。

头部开关注册进 `conversation.session.header.actions` 并把视图绑定到该会话；侧边栏面板注册进 `sidebar.workbench`，中间列编辑器注册进 `workbench.viewer`。一个状态句柄（在插件体内创建，绝不放在模块级）通过 slot inject 闭包被各注册共享，因此开关、侧边栏与编辑器在打开状态、绑定会话、活动文件与所选侧边栏标签上保持一致，而无需 slot store 席位（该席位禁止一个句柄跨两个作用域）。工作台视图激活时，布局交换中间列与右侧列的角色，对话在交换中保持 React 身份。

文件树是懒加载的：根目录在挂载或会话/cwd 变化时列举，每个目录点击展开、缓存列表、再次点击折叠。右键上下文菜单可新建文件与文件夹、重命名、删除（走网关文件系统动词），操作后刷新受影响的目录。代码文件在 CodeMirror 编辑器中打开，具备语法高亮、行号、搜索与版本守卫的保存（Ctrl+S 或头部按钮）；Markdown 文件通过 MarkdownText 渲染。标签栏支持右键批量关闭（本页/其他/全部），切换或关闭标签前若存在未保存编辑会先确认。终端面板以标签形式维持每个会话的持久 shell（Windows 上为 PowerShell，其他平台为 bash）——用「+」新建终端、可清屏、支持每个终端的上下键命令历史。Git 面板展示 VSCode 风格的已暂存/未暂存/未跟踪更改列表，带逐行高亮的统一 diff，支持单文件暂存/取消暂存/放弃、全部暂存/全部放弃、拉取/同步/推送、提交信息输入、分支切换与最近提交历史列表。任务面板以实时时长列出该会话的后台 `ctx.jobs` 记录。

## Model Experience

无：工作台为人类渲染宿主文件系统/进程/仓库状态，不触及任何模型请求。

#### KV Cache effect

无：本包从不组装或发送 provider 请求。

## Known Limitations and Deferred Work

- **管道式终端** —— shell 无 PTY，不支持全屏交互程序；目标场景是命令驱动的工作流。
- **Git 面板以读为主** —— 暂不支持 push/pull/fetch、合并冲突解决或提交历史详情视图；状态、diff、提交与分支切换是第一阶段。
- **面板内无工作区选择器** —— 文件树始终浏览绑定会话的 cwd；选择其他目录属于工作区流程的一部分。
- **工作台打开时两列均可拖拽调整** —— 文件树列复用侧边栏拖拽手柄（264–720px），右侧对话列复用详情手柄（300–520px）。
