# DeepSeek Harness 桌面端 GUI 手动测试用例

> 版本：`0.1.0-rc.64`（fork 桌面端）。
> 用途：覆盖桌面端优化（P0→P2 及 P0-A/B、P2-B）后**需要人工界面验证**的项；用「■ 通过 / ☐ 失败 / — 未测」记录。
> 前置：退出旧版，安装本版（或在开发模式 `pnpm run smoke && pnpm start`）。每个用例独立可测。

---

## A. 启动与标题栏

| # | 步骤 | 预期结果 | 记录 |
|---|------|----------|------|
| A1 | 双击图标启动 | 出现启动动画/闪屏，1–2s 内进入主界面，无长时间白屏 | |
| A2 | 观察标题栏 | 标题居中“DeepSeek Harness”；左上鲸鱼图标；右侧「最小化 / 最大化 / 关闭」三按钮 | |
| A3 | 点最小化 | 窗口缩到任务栏（非托盘）；任务栏图标可恢复 | |
| A4 | 点最大化 | 窗口最大化，右上图标变“还原”；再点还原 | |
| A5 | 标题栏空白处双击 | 最大化/还原切换 | |
| A6 | 点关闭 | **不退出**，隐藏到系统托盘，弹出“已最小化到系统托盘”通知 | |
| A7 | 点托盘图标 | 显示/隐藏窗口 | |
| A8 | 托盘右键 | 出现「显示 / 隐藏」「退出 DeepSeek Harness」 | |
| A9 | 切换系统深色 | 标题栏鲸鱼变近白色（currentColor），标题栏背景/文字随主题；浅色同理 | |

## B. 工作台窗口（VSCode 模式，P2-11 / P0-2）

| # | 步骤 | 预期结果 | 记录 |
|---|------|----------|------|
| B1 | 点“工作台”入口 | 打开分离工作台窗口，主窗口自动隐藏 | |
| B2 | 观察工作台窗口标题栏 | 标题为“DeepSeek Harness 工作台”；URL 含 `dshWindow=workspace` | |
| B3 | 在右侧对话区切换会话 | 会话切换正常；左侧资源管理器/文件树内容随会话动态更新 | |
| B4 | 点工作台窗口的 X | 隐藏到托盘（不退出、不恢复主窗口） | |
| B5 | 点“回到原桌面”按钮 | 主窗口恢复显示并聚焦，工作台窗口关闭 | |
| B6 | 工作台模式下点托盘图标 | 聚焦/切换工作台窗口，**不**同时显示主窗口 | |
| B7 | 开启 `releaseMainRenderer` 后重复 B4/B5 | 进入工作台主窗口渲染器释放（内存下降）；“回到原桌面”后主窗口重新加载并恢复，无白屏/明显卡顿 | |

> 开启方式（可选，默认关闭）：在 `%APPDATA%\dsh-desktop\desktop-settings.json` 写 `{"releaseMainRenderer": true}`，重启应用。
